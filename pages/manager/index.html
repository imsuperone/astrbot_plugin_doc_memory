聊天指令与快速上手
1. 群聊指令快捷管理（仅群管理员）

• /doc：查看清爽指令菜单。
• /doc list：查看知识库中全部入库文档及其 ID。
• /doc status：查看本群当前绑定与生效状态。
• /doc bind <文档ID>：将文档绑定到当前群。
• /doc unbind [文档ID]：解绑文档；不带 ID 则清空本群全部文档绑定。
• /doc mode workspace|system|reference：切换生效模式（模拟工作区 / 强制遵守 / 仅作参考）。
• /doc workspace：查看当前模拟工作区挂载的文件与状态。
• /doc force on|off：切换强制注入系统提示词（清空其他提示词，专属提示词唯一生效）。
• /doc shield on|off：切换人格屏蔽（开启清空原人格，关闭保留原人格）。
• /doc no [off]：清空并忘掉此前所有历史消息（有也忘掉）。
• /doc greeting：查看已绑定酒馆角色卡的开场白问候语。
• /doc search <关键词>：检索当前群绑定的文档内容。
• /doc read <ID> [片段号]：预览文档指定切片内容。
• /doc prompt_set <内容>：设置当前群专属提示词。
• /doc prompt_clear：清空当前群专属提示词。

2. 三大生效模式说明

• ⚡ 强制遵守文档（系统提示词模式）：将文档核心内容直接作为最高优先级系统提示词载入大模型，专属提示词作为额外提示词追加，强制 AI 无条件遵守并执行文档里的角色设定与规则。
• 💻 模拟工作区模式（项目沙箱）：将绑定的文件作为工作区沙箱挂载，大模型严格基于工作区内挂载的文件进行专业分析、开发与解答，0其余说教提示词。
• 📖 仅作参考资料模式（知识库问答）：文档作为外部知识库，提问相关内容时自动检索切片作为参考资料引用回答。

3. 零 Embedding 检索原理与 Token 节省

本插件无需额外配置向量模型（Embedding），通过中英文分词与 TF 动态加权机制进行快速精准定位，自动提取 Top-K 切片注入大模型上下文，极大降低 Token 消耗并保持极速响应。
